# ドッグサロン AIチャットボット 構築指示

ドッグサロン向けの AIチャットボットを作ってほしい。お客さんが Web から気軽に店舗やメニューについて質問できるようにする。

## 利用シーン
ホームページの右下にチャット起動ボタンを設置し、クリックでチャットウィンドウが開く。初めて使う人には最初に性別と居住地を選んでもらい、その後は自由に質問できるようになる。

## チャットの内容
ドッグサロンの案内に特化した AI チャットボットで、会話は自然な日本語、装飾記法は使わずシンプルに。お店に関係しない質問は丁重にお断りする。同じ人が短時間に大量送信できないよう、人ごとに時間あたりの送信上限を設ける。

## AIが応答時に内部で使える機能
- 店舗の基本情報（店名、営業時間、電話番号、住所）の案内
- 店舗の場所案内（Google Map で開くリンクを添える）
- メニューの検索（名前やカテゴリで絞り込み）

メニューを返すときは、画像や金額を含むカード形式でわかりやすく表示する。メッセージ内に URL が含まれていたら、自動でクリックできるリンクにする。

## 管理者向け画面
管理者が会話ログを一覧で閲覧できる画面を別ページに用意する。日時や条件で検索でき、件数が多いときはページ送りができる。

## 埋め込みウィジェット
他サイトに簡単に貼り付けられるよう、JS ライブラリとサンプル HTML を用意する。
- 起動ボタンは画面右下に固定表示の横長ピル型
- 背景は AI らしい青〜紫〜ピンクのグラデーションで、ゆっくり動かす
- クリックするとチャット画面が iframe で開く

## 技術・運用面
- バックエンドは Python、フロントエンドは TypeScript（Next.js）で実装する
- データベースは MySQL を使用する
- フロントエンド・バックエンド・データベースをまとめて Docker で起動できるようにする
- LLM は Google Gemini 2.5 Flash を使用し、ツール呼び出し（Function Calling）で内部機能を呼び出す
- メッセージや UI 表記はすべて日本語
